Data for the map at https://ciaran-matthew-dunne.github.io/paris/, built from open data:

- APUR: buildings, water, city blocks, arrondissements (ODbL)
- Ville de Paris open data: green spaces, trees (ODbL)
- Île-de-France Mobilités: lines and stations
- © OpenStreetMap contributors: parks, woods, monument parts, railway tracks (ODbL)
- IGN RGE ALTI: elevation (Licence Ouverte)

What is derived from ODbL sources is shared under the ODbL.

This branch holds a single commit, replaced each time the data changes: do not base work on it.
